# Mitchell Haw Website

SEO-first Astro website for Mitchell Haw, focused on SEO, AI Search, local SEO, and digital visibility services in Bend and Central Oregon.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Deploy

Connect this GitHub repo to Cloudflare Pages.

Build command:
```bash
npm run build
```

Build output directory:
```bash
dist
```
